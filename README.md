# Карточка проекта К13 · логи

## Исследовательский вопрос
Когда наивное среднее завышает или занижает долю успехов новой системы и помогает ли WIS?

## Данные и срез
MovieLens 1M; 500 случайных пользователей, от 20 оценённых фильмов; seed=13; успех: рейтинг >= 4.; лицензия: GroupLens MovieLens Dataset Usage License (non-commercial research use)

## Эталон и метод
Эталонный исход или прокси: Эталон: доля рейтингов >= 4 среди всех выбранных пар при равномерном выборе пользователя и фильма. Только для этой симуляции.
Оцениваемый оценщик: WIS = сумма(вес * успех) / сумма(весов); вероятности задаём в симуляции.
Базовое сравнение: Наивная оценка = число успехов / число показов в старом журнале.

## Метрика и критерий
Метрика ошибки: MAE = сумма(|оценка - эталон|)/B; смещение = сумма(оценка - эталон)/B. Для обоих методов, в п.п.
Численный критерий успеха: Абсолютное смещение >= 2 п.п. считаем существенным; порог согласовать с куратором.

## Риск и границы
Возможная ошибка оценщика: Перекос показов и большие веса WIS; неизвестные рейтинги нельзя считать нулями.
За границами проекта: Один датасет, WIS и наивное среднее; без обучения моделей. Рейтинг >= 4 — прокси, не реальная конверсия. CPU, прогон до 10 минут.
