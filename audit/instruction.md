# Инструкция разметки команды К13

- Команда — K13
- Направление — logs
- Дорожка — B
- Версия — 1.0
- Дата — 23 ноября 2026 года
- Участники — A1, A2, A3

## Что является объектом

Каждая строка файла среза содержит агрегаты по истории одного участника
MovieLens 1M и по одному имитированному журналу показов для этой истории.
В истории успех означает оценку не ниже 4. Равномерная целевая политика
выбирает среди уже оценённых пользователем фильмов, поэтому её доля успехов
равна отношению числа успехов в истории к числу оценённых фильмов.

Наивная оценка — доля успешных показов в журнале. В журнале могут повторяться
фильмы. Поля "target_success_rate" и "log_success_rate" показывают эти две
доли. Их также можно посчитать по числителям и знаменателям из полей
"history" и "simulated_log".

## Метки и правила

1. Найдите строку по "id" из своей таблицы.
2. Вычислите разницу между долей успехов в журнале и целевой долей.
3. Поставьте одну из меток.

| Метка | Когда ставить |
| --- | --- |
| OVER | Журнальная доля выше целевой на 2 процентных пункта или больше. |
| UNDER | Журнальная доля ниже целевой на 2 процентных пункта или больше. |
| CLOSE | Абсолютная разница меньше 2 процентных пунктов. |

В CSV заполняйте только "label" и "elapsed_seconds". Записывайте фактическое
время разметки объекта целым числом секунд. Остальные поля уже заданы.
Результаты простой базовой линии и зондов смотрите после своей разметки.

## Неоднозначные случаи

На границе 2 п. п. вычислите разницу по исходным числителям и знаменателям
без округления. Если отсутствует объект или знаменатель равен нулю, оставьте
метку пустой и сообщите команде ID, который требует исправления.
Не обсуждайте метки до того, как участники запишут свои ответы.
Первые 10 объектов используйте как пилот. При изменении правил сохраните
версию 1.1 и укажите её для суждений после изменения.

## Парные сравнения

Каждый объект оценивается по одному и тому же правилу. Порядок предъявления
в CSV задан как NA.

## Как получен срез

По карточке К13 из пользователей с 20 или более оценками выбраны 500
случайных пользователей с seed 13. Из этой выборки тем же генератором
выбраны 52 разные истории. В срезе 20 объектов core и 32 second.

Для каждого пользователя популярная группа — верхняя пятая его оценённых
фильмов по числу оценок во всём датасете, с округлением вверх. При равной
популярности порядок определяется идентификатором фильма. Целевая политика
равномерна по его оценённым фильмам. Логирующая политика смешивает целевую
политику с равномерной по популярной группе. Доля второго компонента —
"logging_mix", одно из значений 0, 0.5, 0.9. Для каждой истории и каждого
значения доли сымитировано 10 000 показов с возвращением. Сценарии
распределены по срезу циклически после выбора пользователей.

В baseline_predictions.csv вердикт получен из наивной оценки по README.
Для каждого объекта доля успехов в журнале сравнивается с эталонной долей
по тем же порогам, которые указаны в правилах разметки. Сверку с вердиктами
выполняют после независимой разметки.

Отдельный пилот для probe_results.csv следует плану из README. Для каждого
значения alpha сгенерировано 100 журналов по 10 000 показов. В каждом
показе пользователь выбирается равномерно из тех же 500 пользователей,
затем фильм выбирается по логирующей политике. Общий эталон — среднее
равномерных долей успеха по 500 пользователям. Наивная оценка и WIS
считаются на одних и тех же журналах. Сравниваются MAE и среднее смещение
в п. п. Для WIS используется отношение вероятностей показа при целевой
и логирующей политике. ESS равен квадрату суммы весов, делённому на сумму
их квадратов. При alpha = 0 веса равны единице и WIS совпадает с наивной
оценкой в каждом журнале.

Порог в 2 п. п. взят из карточки К13 как рабочий порог для этой разметки.

Источник — [GroupLens MovieLens 1M](https://grouplens.org/datasets/movielens/1m/).
F. M. Harper и J. A. Konstan, The MovieLens Datasets: History and Context (2015).
В срезе сохранены агрегаты симуляции без исходных строк рейтингов.
[Копия файла рейтингов, использованная для расчёта](https://github.com/gtshs2/Autorec/blob/bca30ff948b916a3748b3c10f11c00e2027df2ef/data/ml-1m/ratings.dat). Для отбора и симуляции использован numpy.random.default_rng(13).
